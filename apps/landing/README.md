# landing

Marketing site and documentation for Zerosend.

- `/` - product landing page
- `/docs` - Fumadocs-powered docs (MDX in `content/docs`)

Dev from repo root:

```bash
bun run dev:landing   # http://localhost:3000
bun run dev:all       # zerosend + landing together
```

Deploy: `bun run deploy:landing` or see [DEPLOY.md](../../DEPLOY.md).
